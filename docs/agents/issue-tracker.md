# Issue tracker: GitHub

Issues, specs, and tickets live in GitHub Issues for `MRYingLEE/browser-ai-connector`.
Use the `gh` CLI from the connected local clone.

- Create: `gh issue create`
- Read: `gh issue view <number> --comments`
- List: `gh issue list`
- Comment: `gh issue comment <number> --body "..."`
- Labels: `gh issue edit <number> --add-label "..."`

Publishing a spec or ticket means creating a GitHub issue. PRs are not a triage surface.
